### git

- git = 버전관리 시스템
- github라고 하는 이유?
    - git 을 인터넷에 공유해주는 서비스
- 분산형 버전 관리 시스템
    - 여러 곳에서 관리해줌므로써 백업이랑 비슷한 느낌
    - 코드 히스토리와 코드를 여러곳에서 안전하게 관리함

### 리눅스 명령어

- 개발할 때 리눅스를 사용하는 이유
    - 호환성이 좋기 떄문에
- 커널 kernel
    - 운영체제의 핵심부품으로, 하드웨어와 소프트웨어를 연결하는 역할
    - CPU, 메모리, 디스크 등의 자원을 관리한다.
    - 사용자, 하드웨어 간의 중재 역할로 프로그램이 안정적이고 효율적이게 실행되도록 함
- 명령어
    - `ls` : 현재 폴더에 있는 파일과 목록 보여줌
        - `ls -alt`
            - -a : 숨긴 처리된 파일이나 디렉토리까지 출력
            - -l : 파일이나 디렉토리의 이름과 속성정보까지 출력
            - -t : 수정 또습 생성된 시간 순으로 정렬하여 출력
    - `cd` : 디렉토리 이동할때
    - `pwd` : 현재 위치한 디렉토리(절대경로 파악할때 사용)
    - `mkdir` : 새로 경로 만들거나 폴더 만들때
    - `touch` : 파일 생성할 때 사용
    - `rm` : 완전 삭제
    - `mv  <이동할 파일 이름> <이동할 파일 경로>`: 이동
- 파일 내용 확인 명령어
    - `cat` : 특정 파일에 기록된 텍스트를 확인
        - grep 을 이용해서 키워드 검색 가능
    - `less` : 한 번에 보여지는 만큼만 읽어서 보여줌, 용량 클 때 유용
    - `head` : 텍스트된 파일의 앞부분을 지정한 만큼 출력하는 명령어
        - `head -n 2 <텍스트가 입력된 파일 이름>`
            - 2줄 출력
    - `tail` : 끝 부분 보여줌
    - `nano, vim` : 텍스트 편집기
- 기타 명령어
    - `clear` : 터미널 입력 화면 한 번에 정리
    - `history` : 최대 1000개 까지 이전의 명령어 출력
    - `echo` : 터미널에 입력한 텍스트를 출력 , 변수를 표시할 때 사용
    - `df` :  디스크 용량, 최상위 디렉토리에서 전체용량 조회
        - df -h : 읽기 좋게 출력
    - `du` :  개별 경로에서 사용 중인 디스크 용량에 대해 조회
        - du -sh
    - `whoami` : 사용하고 있는 유저 정보 출력
- git 과 자주사용되는 조합 명령어
    - `git rm` : git 저장소에서 파일 삭제할 때 사용하는 명령어
        - 파일을 워킹 디렉토리(로컬)와 스테이징 영역(인덱스)에서 모두 제거
    - `grep` :   필터링
        - `grep “<찾으려는 문자열>” <문자열을 검색하고자하는 파일 이름>`
